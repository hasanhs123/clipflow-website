How ClipFlow works

A straightforward flow with TikTok authorization and creator-controlled publishing.

Connect an account

The creator signs in with TikTok and grants the permissions requested by ClipFlow. ClipFlow does not ask for the creator's TikTok password.

Prepare a video

The creator selects a video file to publish. The video is processed according to the requirements of the publishing service.

Publish directly

After the creator confirms the action, ClipFlow submits the authorized publishing request to TikTok.

Review the result

ClipFlow records the publishing result so the creator can identify successful or unsuccessful requests.

ClipFlow only uses TikTok account access that a user has explicitly authorized. Users can contact us about access, privacy, or deletion requests.

Privacy and security

We aim to minimize the information collected and use it only for the services described here.

No TikTok password

Authentication is handled through TikTok's authorization system rather than by asking users to provide their TikTok password to ClipFlow.

Limited data use

Only data needed to operate the connected publishing workflow is intended to be processed.
